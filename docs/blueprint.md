# **App Name**: Pelham Auto Outfitters

## Core Features:

- Photo Gallery: Display a gallery of before-and-after photos of vehicles with lift kits and leveling kits installed.
- Quote Request Form: Allow users to submit a form with details about their vehicle (make, model, year) and the type of lift kit or leveling kit they are interested in.
- Contact Information: Provide a page with the company's contact information (phone number, address, email) and a map showing the shop's location.

## Style Guidelines:

- Primary color: Black (#000000) for a sleek and professional look.
- Secondary color: White (#FFFFFF) for contrast and readability.
- Accent color: Bright red (#e30613) for buttons, links, and highlights to draw attention.
- Clean and readable sans-serif fonts for body text and headings.
- Use a grid-based layout for consistent spacing and alignment.
- Simple and modern icons to represent different services and benefits.
